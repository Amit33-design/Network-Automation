Connect to edit

Changes are saved into the GitHub repository, so everyone who opens this page sees them. Saving needs a GitHub access key. You only enter it once on each phone or computer.

  1. Open GitHub → new fine-grained token.
  2. Repository access: Only select repositories → .
  3. Permissions → Repository permissions → Contents → change “Read-only” to Read and write. Generate and copy it.
